# PRD：小算盘官网和回调页

## 做什么
给多多进宝开放平台的应用"小算盘"准备两个能公开访问的网页，用于填写应用信息：

- 官网地址：产品介绍页，写明产品名、面向谁、做什么、不做什么。
- 回调地址：OAuth 授权完成后跳回的页面。现在只用多多客接口（搜商品、生成推广链接），用不到授权，页面只需要能打开并说明用途。

## 为什么
开放平台创建应用时这两项必填，审核时可能会打开检查。页面打不开或空白容易被驳回。

## 业务规则
- 名称统一用"小算盘"，不出现"多多""拼多多"等官方品牌词，也不用竞品品牌名。
- 不用拼多多的 logo 和商品图。
- 简介和应用说明一致：用户说出想买的商品，系统通过多多客接口搜商品、比较券后价，生成带推广位的链接，用户跳转到官方页面自己下单付款。不代下单，不收集支付信息。页面上"多多客接口"写成"电商平台官方开放的推广接口"，避开品牌词。
- 回调页不处理、不展示、不记录 URL 里的任何参数（如 `code`、`state`）。

## 不做什么
- 不接 OAuth，不换 token，不写后端。
- 不做多多进宝接口调用（另开功能）。
- 不改 MCP 插件（`src/`、`bundle/`、`.claude-plugin/`、`skills/`）。

## 托管
仓库改为公开，用 GitHub Pages 发布（用户 2026-11-09 选定）。
