# 测试文档：小算盘官网和回调页

## 自动化用例（`test/site.test.ts`）
| 编号 | 规则 | 判定 |
|---|---|---|
| S1 | 官网有产品名 | `site/index.html` 的 `<title>` 和 `<h1>` 含"小算盘" |
| S2 | 官网写明不代下单、不收集支付信息 | 正文含"不代用户下单"和"不收集" |
| S3 | 不出现官方品牌词 | 两个页面都不含"拼多多""多多进宝""多多客""Pinduoduo"（失败情况：出现任一词即失败） |
| S4 | 回调页不处理 URL 参数 | 回调页没有 `<script>` 标签 |
| S5 | 不加载外部资源 | 两个页面没有 `src=` 或 `href=` 指向 `http(s)://` 的外部地址 |
| S6 | 关闭 Jekyll | `site/.nojekyll` 存在 |
| S7 | 适配手机 | 两个页面都有 `<meta name="viewport"` |

## 手工验收
由 Agent 在部署后执行，用户复核：
- `curl -I` 两个地址都返回 200。
- 带参数访问 `/pdd/callback/?code=test&state=x` 返回 200。
- 用户在开放平台填入这两个地址，提交后没有因为地址被驳回。

## 不测的
- 页面视觉效果：只有两个静态页，手机上看一眼就够。
- 平台审核结果：取决于平台，无法自动化。
